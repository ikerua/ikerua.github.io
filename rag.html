RAG sobre base documental

Sistema de generación aumentada por recuperación (RAG): indexa una base de conocimiento a partir de documentos y usa un modelo de lenguaje para responder preguntas fundamentadas en ese contenido, en lugar de depender solo de su memoria interna.

Cómo funciona

El sistema parte de una colección de documentos, que se trocean e indexan para poder recuperar los fragmentos más relevantes ante cada pregunta del usuario. Esos fragmentos se inyectan como contexto en el prompt de un modelo de lenguaje, que genera la respuesta final apoyándose en información real en lugar de inventarla.

Esta arquitectura reduce alucinaciones y permite que el sistema responda sobre contenido que el modelo nunca vio durante su entrenamiento.
